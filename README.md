# Weekday Task Garden

Build a cute, aesthetic weekly todo web app that looks exactly like the attached design.

Design & Styling:

Features a soft, playful pastel floral background pattern.

The main interface is centered inside a clean, white mobile-style container with very rounded corners.

Uses a minimalist typography with a clean header titled "Todo - Week".

Layout & Components:

Grouped by days of the week starting with Monday and Tuesday.

Each day section features a cute flower icon.

Each day section has a green circular "+" button to add a task.

The task creation form includes input fields for "Title" and "Deadline".

The form also includes a text area for "Description text that describes the task...".

The form contains four pastel color selection dots and a "Send task" button.

Task cards are rendered in pastel colors (pink, yellow, blue) matching the chosen tag color.

Each task card displays the title, deadline, description, and a checkbox status icon on the left.

Interactivity & Functionality:

Allow users to click the + button to open the task creation form for that specific day.

Users should be able to type a title, deadline, and description, choose a color tag, and click "Send task" to add a new task.

Users can toggle task completion status by clicking the checkbox icon on the left of each task.

Store tasks in local state so they persist during testing.
